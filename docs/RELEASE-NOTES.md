# SSHGuard v0.3.13

## 本次更新

- 修复 Cloudflare 统计及 JavaScript Detections 的 CSP 兼容性：使用每次请求生成的随机 nonce，限定统计脚本来源；应用模块跳过 Rocket Loader，不放开任意内联脚本。
- 修复 Docker Web 构建缺少 Agent 内部包的问题，并加入 API / Web 镜像构建验证。
- 服务器维护菜单新增管理员专用「删除服务器」及二次确认，事务清理关联历史和凭证，保留操作审计；权限不足与非同源请求无法删除。
- Agent 重新注册后按新凭证自动清空旧待传队列、采集位置和隔离数据；主控 / 服务器身份不匹配时自动恢复采集。正常重启及程序更新保留状态。
- 精简 Linux / Windows、amd64 / arm64 Agent，移除运行时正则依赖及未使用的 HTTP/2 代码，保留 HTTPS 验证、WebSocket、断线队列和自动更新；Linux 体积缩小约 9%–10%。
- 队列统计和采集位置改用事务提交后的内存缓存，空闲文件采集减少分配与状态查询；长日志不再被小字段整段持有。空闲轮询自适应放缓，队列满时暂停启动读取进程。
- 网卡地址按分钟缓存，IPv4 / IPv6 独立探测并退避重试，减少重复请求和闲置连接。
- Windows 自动更新遵循系统执行策略，迁移本安装创建的旧维护任务，拒绝其他安装或附加命令的同名任务；更新任务 ID 与版本长度增加校验。
- 修复中文诊断截断后的乱码，补齐队列异常说明、通知投递失败及维护请求错误的中文提示，明确重复删除的错误信息。

## 更新

```sh
sh /opt/sshguard/update.sh
```

先更新主控，再通过「更新命令」或「平台更新」升级 Agent。旧安装可使用 [拉取最新更新脚本](QUICKSTART.md#拉取最新更新脚本)。

重新执行安装命令注册会清空本地未上传队列与采集位置；需要保留时先等待上传完成。删除服务器会永久清除其平台事件、告警和投递记录，操作审计保留；目标机器上的 Agent 需另行卸载。

Windows 更新遵循管理员配置的 PowerShell 执行策略。更新前备份数据库、配置和 ENCRYPTION_KEY。
