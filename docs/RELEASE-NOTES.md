# SSHGuard v0.3.10

## 本次更新

- 告警支持勾选批量确认和跨分页全部确认，保留权限、同源校验和审计保护。
- SSH 事件显示来源国家 / 地区与国旗，支持公网 IPv4 / IPv6，查询失败不影响事件查看。
- 首页增加认证失败来源国家 TOP 5 和最近事件区块，提供过渡动画、事件详情与完整列表入口。
- 所有菜单支持独立路由、刷新恢复、前进 / 后退；分页和筛选条件保存在地址中。
- 改善并发统计与 GeoIP 查询：合并重复请求，单个页面取消不会影响其他查询，配置更新会使旧统计缓存失效。
- 本版包含服务器 GeoIP 设置、公网地址识别及确认弹窗宽度修复。

无需新增数据库迁移。升级前备份数据库、配置和 ENCRYPTION_KEY，按 [快速开始](QUICKSTART.md) 更新。完整增量验证见 [验证记录](VALIDATION.md)。

## 既有功能与升级约束

- 刷新统一到顶栏，退出改为箭头图标；侧栏图标对应功能并增加交互动效，全站弹窗统一为居中标题、表单与底部操作区，配色沿用浅色 / 深色主题。
- 主题切换采用圆形扩散，统一过渡速度与结束处理，避免图表同时重播动画；精简登录页提示与 README。
- 服务器列表改为紧凑行，增加可复制的 IPv4 / IPv6，维护操作收进菜单；移除重复标题、宣传文案、统计卡片脚注和页脚。
- 安装 / 更新窗口改为系统标签、上报设置与复制命令；右上角只显示一个 Admin，审计动作与角色显示中文，SSH 事件补齐来源端口。
- 增加独立 IP 白名单，支持 IP / CIDR、IPv4 / IPv6；仅免除 SSH 事件告警，保留原始事件，变更受角色、同源校验和审计保护。
- 安装时可选择 1–30 秒上报，默认 5 秒；安装凭证绑定间隔并写入 Agent 配置，运行期不接收配置变更，更新保留原值；Agent 保留采集上报与平台触发固定版本更新。
- 修复 Alpine 标准 BusyBox syslog 的采集权限：专用 root:sshguard 认证日志和 setgid 目录，Agent 不加入 wheel；同版本更新也修复权限。
- 总览图表使用 ECharts，支持面积曲线、过渡动画、悬停 / 键盘明细和 24 小时 / 7 / 14 / 30 天；增加全站深色模式和持久化切换按钮。
- 审计增加来源 IP 与 UA，只信任显式配置的代理（默认仅本机回环）。
- 总览统计共享 5 秒短缓存，页面刷新合并；无变化文件不落盘，地址不重复更新，心跳错误日志限频，保留断线队列与资源回收验证。
- Windows 生成的安装 / 更新 / 卸载命令遵循当前 PowerShell 执行策略，取消主动指定 Bypass；本地预览直接启动编译程序。
- 安装脚本和 Agent 改为直接下载本项目 GitHub Release 的固定版本；校验 SHA-256 与版本号后替换，失败保留原服务。

## 登录防护

新增三选一的人机验证和 60 秒错误 5 次封禁来源 IP 24 小时。默认不启用第三方验证码，封禁规则始终启用；管理员在「登录防护」填写服务商密钥与允许的网站主机，输入当前密码后保存。第三方故障不会放行，也不会累积封禁计数。配置步骤和本机恢复见 [登录防护](LOGIN-SECURITY.md)。

## 升级须知

先备份数据库、setup.json、api.env 和 ENCRYPTION_KEY，再升级主控，随后更新 Agent。程序回退不撤销数据库结构变更。

上报间隔默认 5 秒，仅在安装窗口选择 1–30 秒，注册成功后写入 Agent 配置。编辑服务器、更新窗口和心跳确认均不能更改运行中的间隔。

Alpine 使用专用认证日志。目标机器需能访问 GitHub Release，Windows 需系统自带 curl.exe。自定义 syslog 选项、其他日志服务或显式 log_file 需按本机权限策略配置，详见 [Agent 手册](AGENTS.md)。

IP 白名单作用于 SSH 来源告警，不限制控制台访问，不修改防火墙，不删除事件或已有告警。

反代审计来源默认信任本机回环地址。跨机 / Compose 代理应将 TRUSTED_PROXY_CIDRS 配置为准确代理 IP 的 CIDR，并限制 API 只接收该代理连接，详见 [反代说明](REVERSE-PROXY.md)。自定义端口仍需手动同步 PUBLIC_URL。

图表统计采用 5 秒短缓存；7 / 14 / 30 天按 UTC 日汇总，小时明细按浏览器本地时区显示。主题首次跟随系统，手动选择保存在当前浏览器，可跨页面与刷新保留。动画尊重减少动态效果设置。

Windows 命令不主动绕过执行策略；受组织签名策略限制时，按组织批准的分发流程运行。固定维护任务仅运行预置更新器。杀毒告警不能仅凭截图认定误报，未进行厂商复核或代码签名认证，也不承诺无告警。

安装与升级见 [快速开始](QUICKSTART.md)，验收范围见 [验证记录](VALIDATION.md)。
