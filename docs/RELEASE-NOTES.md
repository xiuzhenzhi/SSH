# SSHGuard v0.3.17

- 修复目录重构后国旗资源路径失效的问题，恢复服务器列表、SSH 事件、国家排名和最近事件的国旗。资源路径改为从前端项目根目录解析，避免组件移动再次影响资源打包。
- 增加生产打包回归检查，逐一验证所有国家 SVG 都包含在构建结果中。
- 精简安装命令弹窗，移除 Linux 和 Windows 环境说明段落。

## 更新

```sh
sh /opt/sshguard/sshguard.sh --update
```

更新后刷新浏览器。本次仅修复主控前端，Agent 保持 0.3.16，无需为恢复国旗重装 Agent 或更改 GeoIP 配置。从旧仓库地址版本升级，请使用下方指南中的最新更新脚本。

升级前备份数据库、配置和 ENCRYPTION_KEY。详见[快速开始](guides/QUICKSTART.md)。
