- 新增统一 `sshguard.sh`，集中安装、更新和服务管理；简化主控与 Agent 安装提示。运行包和默认源码归档不包含 docs，文档在在线站点查阅。

- 新增数据库页面：SQLite 空间回收、PostgreSQL 清理分析、MySQL 表优化，以及三类记录的持久化保留策略。后台维护提供权限检查、同源校验、重复任务保护与操作审计，服务退出等待任务清理。
- 服务器名称改为可选，空白时自动命名；创建按钮简化为「添加服务器」，阻止重复提交。
- 更新安装、维护、数据库、开发、接口与发布文档，保留旧文档地址跳转。

## 更新

```sh
sh /opt/sshguard/sshguard.sh --update
```

旧安装可继续执行 `sh /opt/sshguard/update.sh`，或使用[快速开始](guides/QUICKSTART.md)中的最新脚本。升级前备份数据库、配置和 ENCRYPTION_KEY；本次会增加数据保留设置表。数据库类型不会自动切换，回退程序不会撤销迁移。

数据库维护不删除现有记录；缩短保留期限会在自动清理时永久删除过期记录。PostgreSQL 的普通 VACUUM 主要复用空间，MySQL 优化可能重建表并短暂锁表。详见[数据库与数据保留](guides/DATABASE.md)。
