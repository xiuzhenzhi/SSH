# SSHGuard v0.3.15

- 主控和 Agent 独立版本；复用未变化的 Agent 产物，按组件选择数据库、前端和部署检查，文档不再随版本号空转。
- Agent 卸载默认清除本地配置、凭据、队列、采集状态和专用日志，并清理 Windows 事件源。
- 修复未认证登录请求耗尽全局额度导致其他用户及管理操作被限流的问题；按来源与用户隔离额度，并限制并发。
- 修复倒序及跨批次迟到的 SSH 失败事件遗漏阈值告警的问题，保留时间窗口、去重和冷却约束。
- 增加限流隔离、倒序上报、跨批次迟到及窗口边界回归测试。

升级前备份数据库、配置和 ENCRYPTION_KEY。安装与升级见 [快速开始](guides/QUICKSTART.md)。

## 主分支后续变更（未包含在 v0.3.15 安装包中）

- 最低兼容范围调整为 v0.3.14；移除更早的 MySQL 迁移适配、Windows 维护任务格式和目录式安装卸载分支。
- 文档首页改用现行路径，移除旧地址跳转和更早版本历史内容。
