# SSHGuard v0.3.12

## 本次更新

- Agent 安装、更新和卸载统一为 Linux / Windows 两项，Linux 自动识别系统、架构与运行权限。
- 修改上报间隔后自动更新安装命令，无需再手动生成；连续改值时以最新选择为准。
- 移动端登录页隐藏宣传文案并压缩顶部留白，保留品牌和主题切换；密码输入使用适合手机的字号。
- 移动端导航改为左侧抽屉，支持纵向滚动、遮罩关闭、Esc 关闭和页面切换后自动收起；桌面保留固定侧栏。
- 统一登录页及组件的简体中文提示，补齐对话框关闭、下拉框和空表格等默认文案。
- 登录增加空字段、验证码就绪和重复提交检查；服务端通知会话失效时立即清除本地页面状态并返回登录页。

## 更新

```sh
sh /opt/sshguard/update.sh
```

旧安装使用 [拉取最新更新脚本](QUICKSTART.md#拉取最新更新脚本)。更新前备份数据库、配置和 ENCRYPTION_KEY。
