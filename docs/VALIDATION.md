## 本机与交互检查

- 完整 Go 测试、vet、Vue 类型检查、生产构建、文档链接与工作流语法检查通过。真实 API / Agent 验证直连、注册、上报、事件与重启持久化；真实 Nginx HTTPS 验证 Cookie、Origin、WebSocket 与敏感文件隔离。
- 隔离 Alpine 3.21.9 验证专用日志 root:sshguard、目录 2750、文件 0640，轮转后采集账号仍可读取。

- 登录验证覆盖三家服务端协议、主机与时效、极验签名、令牌重放、异常响应、加密密钥不回显；配置 / 服务错误不计登录失败。5 次封禁、滚动窗口、并发、持久化及解除封禁通过。
