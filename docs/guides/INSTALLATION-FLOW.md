# 主控安装流程

1. 运行安装脚本，选择「1 安装主控」，确认端口。
2. 打开终端给出的初始化链接，创建管理员。
3. 在「服务器管理」添加服务器。
4. 复制对应系统的安装命令，到目标机器执行。
5. 确认在线与采集正常，测试一次 SSH 登录。

安装命令见 [快速开始](QUICKSTART.md)。

## 常见操作

| 情况 | 操作 |
|---|---|
| 8080 被占用 | 安装时加 `--port 8081` |
| 初始化链接丢失 | 菜单「8」 |
| 更新主控 | 菜单「9」 |
| 卸载主控 | 菜单「7」，保留数据 |
| 卸载 Agent | [按系统手动卸载](UNINSTALL.md) |
| 配置 HTTPS | [反代与 HTTPS](../deployment/REVERSE-PROXY.md) |
